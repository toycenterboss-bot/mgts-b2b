## `!important` — 206 вхождений

Это не стилистическая придирка. `!important` появляется там, где слой стилей
проиграл другому слою, и каждый следующий разработчик обязан выиграть тем же
способом. Пока их 206, «поправить цвет в одном месте» физически невозможно —
и именно поэтому 2470 узлов с плохим контрастом нельзя вылечить одной строкой.

**Метрика фазы Ф1: 206 → 0.**

## Иконки — две системы, работает аварийная

| Что | Число |
|---|---|
| Иконок-записей в CMS | 389 |
| Из них с загруженным файлом (набор `svgviewer_*`) | 244 |
| Иконочных слотов на 100 страницах | 7631 |
| Отрисовано картинкой из CMS | **7** |
| Ушло в шрифтовой фолбэк Material Symbols | **7624** (99,9 %) |

Контент ссылается на имена Material Symbols (`chevron_right` — 1442 раза, `bolt` —
1001, `hub` — 519, `cell_tower` — 500). Записи с такими именами в CMS есть, файла
у них нет — срабатывает аварийная ветка `Icon.tsx`. Нарисованные 244 SVG не
используются нигде.

🔴 Побочный эффект: `Icon` — асинхронный серверный компонент, делающий запрос в
Strapi на каждый слот (**до 88 на странице**). Запросы кэшируются
(`cache: "force-cache"` + `revalidate`), так что на прогретом кэше цена невелика —
но на холодном сборка каждой страницы упирается в десятки запросов, каждый из
которых возвращает запись без файла.

## Первоочередные действия

1. **Завести слой токенов** в `globals.css`: 3 поверхности, 4 ступени текста,
   акцент с доступной текстовой парой, 6–7 кеглей, 3 скругления, 3 тени.
   Метрика: 1338 литералов → цель ≤ 100 (остаток — сам файл токенов).
2. **Снять 206 `!important`.** Пока они есть, токены не работают.
3. **Решить вопрос иконок.** Один источник. Если Material Symbols — убрать 244
   мёртвых файла и запрос в CMS на каждый слот; если `svgviewer_*` — перевести
   контент на эти имена.
4. **Завести компонент кнопки** — сегодня его нет, поэтому «первичная кнопка»
   существует в стольких вариантах, сколько раз её написали.
5. **Мобильное состояние шапки** — без него адаптива не будет ни у одной секции.
6. **Гарнитура через `next/font`** — одно объявление вместо пяти.
