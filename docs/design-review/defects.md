# Реестр дефектов дизайна

Дата: 19.08.2026 | Источник: пять отчётов этой папки, базовый прогон 19.08
| Проверяется машиной: `mgts-frontend/scripts/check-defects.mjs`

Отчёт, который не превратился в строку с номером, сроком и числом, — это мнение.
Здесь каждый дефект получает **прибор**, **число сейчас**, **число-цель** и **фазу**,
в которой закрывается. Закрыть дефект можно только сдвигом числа либо явной записью
«отложено, потому что» — третьего машина не принимает (**К-10**: обещание без носителя).

## Как читать колонку «Проверка»

- `design-metrics · <поле> ≤ N` — поле из `metrics-after.json`, снимается
  `node scripts/design-metrics.mjs --out ../docs/design-review/metrics-after.json`
- `design-metrics-mobile · <поле> ≤ N` — то же из `metrics-after-mobile.json` (окно 390×844)
- `ручная · <что смотреть>` — прибора нет; закрывается только с `коммит:<sha>`

## Статусы

`⬜ открыт` · `🟡 в работе` · `✅ коммит:<sha>` · `⏸ отложено, потому что <причина>`
