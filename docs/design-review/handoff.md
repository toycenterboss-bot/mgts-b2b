# Передача в разработку: что именно делается в Ф1 и Ф1.5

Навык: `design:design-handoff` | Дата: 19.08.2026
| Стек: Next.js 16 (App Router, RSC) + Tailwind 3.4 + Strapi 5.36
| Исполнитель: агент | Приёмка: владелец, через PR

Это не спецификация макета — макета нет. Это спецификация **правок по итогам
ревью**: что меняется, чем измеряется, что должно сдвинуться.

## Слой токенов (`src/app/globals.css`)

Единственное место, где цвет разрешён литералом. Значения ниже — из уже
используемой палитры, не новые; в скобках — измеренный контраст на `#0a0f18`.

| Токен | Значение | Где применяется |
|---|---|---|
| `--surface-0` | `#0a0f18` | фон страницы |
| `--surface-1` | `#0f1923` | секции, полосы |
| `--surface-2` | `#1a232e` | карточки, всплывающие слои |
| `--text-1` | `#ffffff` (18,4:1) | заголовки, основной текст |
| `--text-2` | `#9aabbc` (8,16:1) | вторичный текст, подписи |
| `--text-3` | `#e2e8f0` (15,9:1) | текст на светлых плашках |
| `--accent-text` | `#60a5fa` (**7,55:1**) | ссылки и заголовки-ссылки на тёмном |
| `--accent-fill` | `#0066cc` | заливки кнопок и плашек, **не текст на тёмном** |
| `--focus-ring` | `#60a5fa`, 2 px, offset 2 px | видимый фокус |
| `--radius-s / m / pill` | 8 / 16 / 999 px | вместо 31 текущего значения |
| `--elev-1 / 2 / 3` | три тени | вместо 50 текущих |
| шкала кегля | 12 / 14 / 16 / 20 / 24 / 32 / 48 | вместо 53 текущих |

🔴 **`--accent-fill` нельзя ставить цветом текста на `--surface-*`** — именно это
даёт 3,45:1 и 1200 из 2470 нарушений. Правило машинное: см. инвариант ниже.

## Компоненты, которых сегодня нет

| Компонент | Варианты | Состояния | Примечание |
|---|---|---|---|
| `Button` | primary / secondary / ghost | default · hover · active · **disabled** · **loading** · focus-visible | сейчас кнопки собираются классами по месту; компонента в `ui/` нет |
| `SearchField` | header / section | default · focus · **пусто** · **ничего не найдено** | одна метка, один плейсхолдер, `aria-label` обязателен |
| `HeaderMobile` | — | закрыто · открыто · переход | **единственная причина 100 % страниц с боковой прокруткой** |
| `SkipLink` | — | скрыт · в фокусе | «Перейти к содержимому», первым в порядке таба |
| `EmptyState` | страница / раздел / поиск | — | тексты — в `ux-copy.md` |

## Раскладка и точки перелома

| Ширина | Что происходит сейчас | Что должно |
|---|---|---|
| ≥ 1024 px | полная шапка: служебная строка + основное меню + поиск + CTA | без изменений |
| 768–1023 px | то же, ужимается | служебная строка сворачивается в «Ещё» |
| < 768 px | **ничего не меняется** — документ 668 px в окне 390 | служебная строка скрыта, меню в бургере, поиск — иконкой |
| 320 px | не проверялось | контент без горизонтальной прокрутки (WCAG 1.4.10) |

Декоративный слой (`light-leak`, `fixed … w-[500px]`) обрезается контейнером с
`overflow: hidden` — это причина переполнения на 64 из 100 страниц в десктопном окне.

## Крайние случаи

- **Пустая страница.** 10 из 100 сейчас отдают пустое тело. Пустое состояние
  рисуется, а не оставляется белым пятном; `contact` до наполнения снимается с
  публикации, а не показывается пустым.
- **Текст-заглушка.** 17 блоков «Страница услуги …» — после Ф2 такие поля живут
  с `stubStatus: stub` и `expectedForm`, в прод не уходят.
- **Длинный термин.** «Недискриминационный доступ» — 184 px; на мобильном
  служебная строка скрывается целиком, сокращать термин нельзя.
- **Иконка не нашлась.** Сегодня — фолбэк в шрифт, 7624 раза из 7631. Целевое
  поведение: один источник; отсутствие иконки — пустое место, а не «молекула».
- **Гидратация.** 31 страница из 100 расходится между сервером и клиентом.
  До правок темы это чинить не обязательно, но и списывать нельзя.

## Доступность — что обязательно в приёмке

- Порядок таба: skip-link → логотип → основное меню → поиск → CTA → содержимое.
- Видимый фокус собственным токеном, а не умолчанием браузера.
- Высота попадания у всех интерактивных элементов ≥ 44 px.
- `aria-label` у полей поиска.
- Ровно один `h1` на страницу.

## Метрики приёмки Ф1 + Ф1.5

Замер тем же прибором, что и базовый: `node scripts/design-metrics.mjs`.

| Показатель | Базовый прогон | Цель |
|---|---|---|
| Текстовых узлов ниже AA | **2470** | **0** |
| Пар «цвет/фон» ниже AA | 10 | 0 |
| `!important` | **206** | **0** |
| Литеральных цветов вне токенов | **1143** | ≤ 100 |
| Страниц с боковой прокруткой (390 px) | **100 из 100** | **0** |
| Страниц с боковой прокруткой (1366 px) | 64 из 100 | 0 |
| Видов целей меньше 44×44 | **206** | 0 |
| Страниц без `h1` | 13 | 0 |
| Страниц с несколькими `h1` | 7 | 0 |
| Иконок из CMS / аварийных | **7 / 7624** | один источник, ноль аварийных |
| Блоков текста-рыбы | 17 | 0 (или помечены `stubStatus`) |
| Страниц с пустым телом | 10 | 0 опубликованных |
| Изображений без `alt` | 0 | 0 (не ухудшить) |
| Страниц без фокусируемой навигации | 0 | 0 (не ухудшить) |

**Инвариант (класс К-10 — обещание без носителя):** после Ф1 повторный прогон
`design-metrics` обязан показать 0 по строкам «узлов ниже AA» и «`!important`».
Пока показывает не 0 — фаза не закрыта, независимо от того, как выглядит сайт.

**Инвариант (класс К-05 — формальный признак за результат):** отчёты этой папки
сами по себе ничего не доказывают. Доказательство — **разница двух прогонов**
прибора, приложенная к закрывающему блоку Ф1.5.

**Откат.** Документы ничего не исполняют: откат — удаление папки. Скрипт
`design-metrics.mjs` только читает страницы и файлы, ничего не меняет.

## Чего в этой передаче нет

🔴 Макетов. Значения выше выведены из существующего кода и замеров, а не из
дизайна — если у владельца есть макет, он главнее этой таблицы.
🔴 Спецификации анимаций и переходов: не смотрели.
🔴 Светлой темы: кнопка «Светлая тема» в шапке есть, её состояние не измерялось
ни разу — все числа сняты на тёмной.
