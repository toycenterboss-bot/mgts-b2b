# Дизайн-критика: сайт МГТС B2B (базовый прогон)

Навык: `design:design-critique` | Дата: 19.08.2026 | Стадия: **до редизайна**
| Что смотрели: 100 опубликованных страниц, снимки — `/`, `/business`,
`/developers`, `/connecting_commercial`, `/contact` в 1366×900 и 390×844

## Общее впечатление

Тёмная «технологическая» витрина с сильным героем и аккуратной сеткой карточек —
и с тремя разными системами заголовков, одной иконкой на все случаи жизни и
текстом-рыбой в карточках услуг. Самая большая возможность не в перекраске:
**мобильной вёрстки у сайта нет вообще** — на окне 390 px документ шириной 668 px
на всех 100 страницах.

## Юзабилити

| Находка | Важность | Что делать |
|---|---|---|
| Документ шире окна на **100 из 100** страниц в мобильном окне (переполнение до 285 px при ширине окна 390) — шапка не сворачивается, бургер-меню нет | 🔴 | Мобильная раскладка шапки: верхняя служебная строка прячется, основная навигация — в бургер |
| **10 опубликованных страниц** отдают пустое тело: `contact`, `search`, `sitemap`, `ai-chat`, `reports`, `terms`, `essential_facts`, `emission`, `stocks_reports`, `affiliated_persons` | 🔴 | `contact` и `search` — несущие для B2B. Либо наполнить, либо снять с публикации: живой URL с пустым экраном хуже отсутствия |
| Три разных поля поиска с тремя плейсхолдерами: «Поиск услуг…» (шапка), «Найти инновационное решение…» (главная), «Поиск B2B решений…» (раздел) | 🟡 | Один поиск, один плейсхолдер. Разные формулировки читаются как разные поисковые системы |
| Переполнение по горизонтали на **64 из 100** страниц и в десктопном окне — из-за декоративных пятен `fixed … w-[500px]` («light-leak») без `overflow: hidden` у контейнера | 🟡 | Обрезать декоративный слой контейнером. Правка на одну строку |
| Хлебные крошки на `/business`: «Главная → **МГТС - Главная** → Бизнесу» — служебный заголовок записи CMS вылез в интерфейс | 🟡 | Крошки строить по `title`, а не по имени записи; для корня — пропускать |
| Две равновесные кнопки в финальном блоке: «ОСТАВИТЬ ЗАЯВКУ» и «СВЯЗАТЬСЯ С НАМИ» | 🟢 | Одна главная, вторая — текстовой ссылкой |
| Подвал: **60+ ссылок** в двух несовпадающих сетках (5 колонок, потом ещё 5, потом одна) | 🟢 | Свести к одной сетке; «Каталог услуг» не должен висеть отдельной строкой |

## Визуальная иерархия

- **Что цепляет первым.** Гигантский герой «МГТС — НАДЁЖНАЯ ИНФРАСТРУКТУРА
  СВЯЗИ». Это верно по силе, но неверно по смыслу: заголовок ничего не говорит
  B2B-посетителю о том, куда ему идти. Развилки по аудитории в первом экране нет —
  она спрятана в середине страницы под заголовком «НАШИ УСЛУГИ».
- **Ход взгляда.** Герой → второй заголовок с другим начертанием → поле поиска →
  три ряда одинаковых карточек. К третьему ряду карточки перестают различаться:
  одинаковая иконка, одинаковая длина текста, одинаковая кнопка «ПОДРОБНЕЕ».
- **Три системы заголовков на одной странице.** Герой — светлый прописной
  разрядкой; «Технологии, которые двигают ваш бизнес» — жирный строчный с синим
  вторым словом; «ПОЧЕМУ МГТС?», «НАШИ УСЛУГИ» — средний прописной. Ни одна из
  трёх не выглядит ошибкой по отдельности, вместе они читаются как три сайта.
- **Пустота работает против.** На `/contact` между крошками и подвалом ~330 px
  пустоты. Читается как «страница сломалась», а не «здесь ничего нет».

## Доступность (кратко — подробно в `accessibility.md`)

- **Контраст**: 2470 текстовых узлов ниже AA. Основной виновник — фирменный синий
  `#0066cc` на тёмном фоне: 3,45:1 при нужных 4,5:1, и так 1000 раз в `h3`.
- **Тач-цели**: 206 видов элементов меньше 44×44. Вся верхняя служебная строка —
  ссылки высотой 16 px.
- **Читаемость**: основной серый `#4b5563` на `#0a0f18` даёт 2,54:1 — почти вдвое
  ниже нормы.

## Что работает хорошо

- Атрибут `lang="ru"` на всех 100 страницах, `alt` есть у **всех** изображений —
  ноль нарушений, редкость.
- Сетка карточек и вертикальный ритм внутри секции выдержаны; тёмная тема не
  «грязная», фон реально нейтральный.
- Герой на `/business` с диагональной графикой — единственный экран, где
  визуальный язык выглядит намеренным, а не собранным из остатков.
- Навигация присутствует и фокусируема на всех 100 страницах.

## Приоритетные рекомендации

1. **Мобильная шапка и обрезка декоративного слоя.** 100 % страниц с боковой
   прокруткой — это не «недоработка адаптива», это сайт, которым нельзя
   пользоваться с телефона. Дешевле всего и виднее всего.
2. **Контраст фирменного синего на тёмном.** Одно решение на уровне токена
   закрывает 2470 узлов: либо светлее синий для текста, либо синий только на
   светлых плашках.
3. **Определиться с иконками.** Две системы, из которых работает аварийная, —
   худший из вариантов. Пока не решено, каждая новая карточка получает «молекулу».
4. **Пустые страницы.** 10 живых URL с пустым экраном; `contact` — точка входа
   для B2B-клиента.
