# Анализ структуры проекта: категории папок и файлов

**Дата:** 10 марта 2026  
**Назначение:** разнесение репозитория по категориям — локальная версия, React-версия, материалы, старые версии.

---

## 1. Локальная версия (статичный/локальный демо-сайт)

Всё, что относится к **локальному просмотру HTML-шаблонов** (без Next.js): сервер, шаблоны, блоки, CMS-loader. Обычно запускается на **http://localhost:8002** (или другой порт через `design/dev_server.py`).

| Путь | Описание |
|------|----------|
| **design/dev_server.py** | HTTP-сервер с pretty-роутингом: `/news`, `/news/<slug>`, `/<slug>` → шаблоны из `html_pages/`. |
| **design/html_pages/** | Канонические HTML-шаблоны (TPL_*, page_*, code_*): главная, новости, CMS-страница, сценарии, карьера, поиск, AI-чат и т.д. |
| **design/html_blocks/** | Библиотека блоков: каждый блок — папка с `block.html` и `deps.html` (заголовок, герои, футер, модалки, карточки и т.д.). |
| **design/cms_loader/** | Клиентский JS: загрузчик интерактивов, адаптеры (CMS, страницы, новости, секции), мегаменю, обработчики по страницам. |
| **design/assets/** | Общие ассеты для локального просмотра: CSS, изображения, шрифты. |
| **design/tailwind/** | Конфигурация/сборка Tailwind для дизайн-слоя (если используется при сборке HTML). |
| **scripts/dev/** | Скрипты запуска локального окружения: `static_server.py` (альтернативный сервер с маппингом роутов), `start_all.sh`, `stop_all.sh`. |

**Итого (ориентировочно):** ~1 745 файлов, ~376 папок в перечисленных деревьях.

---

## 2. React-версия (Next.js приложение)

Всё, что относится к **фронтенду на React/Next.js**: приложение, компоненты, роуты, стили. Запускается на **http://localhost:3000**.

| Путь | Описание |
|------|----------|
| **mgts-frontend/** | Корень Next.js-приложения (v16, React 19, Tailwind 4). |
| **mgts-frontend/src/app/** | App Router: страницы (`page.tsx`), layout, роуты `[...slug]`, `news/[slug]`, `career`, `contact`, `search`, `ai-chat` и т.д. |
| **mgts-frontend/src/components/** | React-компоненты: layout (Header, Footer), секции, формы, UI (иконки, видео, темы). |
| **mgts-frontend/src/lib/** | Утилиты: Strapi API, маппинг шаблонов/блоков. |
| **mgts-frontend/public/** | Публичные статичные файлы фронта (в т.ч. ассеты для продакшена). |
| **mgts-frontend/scripts/** | Скрипты, связанные с фронтом (если есть). |

**Итого (без node_modules):** ~6 685 файлов, ~131 папка в `mgts-frontend/`.

**Примечание:** Backend (Strapi) — **mgts-backend/** — это отдельный сервис (CMS), он не входит в «React-версию» сайта, но питает и локальные шаблоны (через API), и Next.js.

## 3. Материалы, использованные при создании

Исходники, документация, дизайн-киты, скрипты подготовки контента, временные артефакты импорта и сравнения — всё, что использовалось при создании и миграции сайта.

| Путь | Описание |
|------|----------|
| **docs/** | Вся документация: CMS, интеграция, установка, гайды, статусы, отчёты QA, контракты, планы. |
| **docs/project/** | Контекст проекта, ТЗ, планы миграции, сравнение статик vs React, визуальное сравнение, маппинг страниц/блоков, скрипты (`extract_menu_pages.py`, `site_structure_builder.py`). |
| **docs/project/visual-compare/** | Снимки и отчёты визуального сравнения статичных и React-страниц. |
| **design/Design UI KIT.html**, **design/Design UI KIT.rtf** | Дизайн-кит UI. |
| **design/Идеи для сайта.rtf** | Идеи и заметки по сайту. |
| **design/icon_audit.md**, **design/icon_audit_strapi.md** | Аудит иконок. |
| **design/icon_svgviewer_*.json**, **design/icon_svgviewer_*.md** | Кандидаты и выбранные иконки (nav, pages, версии v24, v24b … v24e). |
| **design/svgviewer_selected/** | Экспортированные/выбранные SVG (каталог иконок). |
| **design/generated_icons/** | Сгенерированные иконки. |
| **design/services/** | Описания/данные по услугам (используемые при сборке или миграции). |
| **design/index.html** | Точка входа/индекс дизайн-слоя. |
| **scripts/penpot/** | Скрипты для Penpot: структура, шрифты, аудит полей. |
| **scripts/stitch/** | Сборка HTML-страниц из блоков (например, `build_html_pages.py`). |
| **scripts/setup/** | Скрипты первичной настройки окружения. |
| **scripts/mapping/** | Скрипты маппинга (страницы, меню и т.п.). |
| **scripts/page_analysis/** | Анализ страниц. |
| **scripts/qa/** | Скрипты QA. |
| **scripts/utils/** | Вспомогательные утилиты. |
| **mgts-backend/temp/** | Временные файлы бэкенда: загрузки документов (doc-files, forms_doc, labor-safety, offers, operinfo, purchas, wca, infoformen и т.д.), кэши, отчёты импорта, извлечённые данные. |

**Итого (ориентировочно):** порядка 2 000+ файлов в перечисленных путях (зависит от объёма `docs/` и `mgts-backend/temp/`).

## 4. Старые версии и бэкапы

Legacy-фронтенд, старые сборки Stitch, бэкапы БД и медиа, медиа до восстановления.

| Путь | Описание |
|------|----------|
| **SiteMGTS/** | Старый фронтенд (legacy HTML) и исходные страницы для миграции контента в Strapi. Структура по разделам: about, business, government, developers, partners, news, contacts и т.д. |
| **design/stitch_header_and_mega_menu/** | Первый набор Stitch-сборок (страницы с хедером и мегаменю). |
| **design/stitch_header_and_mega_menu 2/** | Второй набор Stitch-сборок (расширенный/альтернативный набор страниц). |
| **backups/** | Локальные бэкапы: дампы БД Strapi (`strapi-db-*.sqlite`), бэкапы страниц (`strapi-pages/`). |
| **strapi-backups/** | Дата-папки с полными бэкапами Strapi (структура, контент, медиа). |
| **mgts-backend/public/uploads.pre-restore-20260304-183020/** | Медиафайлы до восстановления (копия uploads на момент 04.03.2026). |

**Итого (ориентировочно):** ~2 500+ файлов в перечисленных путях (сильно зависит от объёма uploads и бэкапов).

## Перекрёстные зависимости

- **Локальная версия** использует контент из **mgts-backend** (Strapi API, медиа с localhost:1337) и общие **материалы** из `design/assets`, `design/cms_loader`.
- **React-версия** тоже ходит в **mgts-backend** за данными; документация в **docs/project** описывает сравнение статик (8002) и React (3000).
- **Материалы** ссылаются на структуру и контент из **SiteMGTS** и Strapi (миграция, маппинг страниц).
- **Старые версии** не должны использоваться в продакшене; при необходимости их можно вынести в архив или отдельный репозиторий.

Если нужно, можно добавить в репозиторий `.cursorignore` или отдельный файл с списком путей по категориям для скриптов/архивации.
