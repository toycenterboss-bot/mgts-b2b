# Инструкция ИИ-агенту — проект MGTS B2B

Дата: 14.08.2026 | Статус: действует | Отменяет: —

## Что делать при старте сессии — в этом порядке

1. `sh memory-bank/check-memory.sh` — ~5 секунд. Если красное, чини до работы.
2. `memory-bank/index.md` — какой файл о чём.
3. `memory-bank/activeContext.md` — что происходит сейчас и что горит.
4. `memory-bank/context/<свой слот>.md` — оперативка своего потока.
5. **После чтения жди инструкций.** Не начинай правки по собственной инициативе.

Если работа касается кода — открой `memory-bank/patterns/catalog.md` и пробегись
по колонке «Триггер». Не читать подряд: найти свой случай.

## Что делать в конце сессии

1. Запись в `memory-bank/inbox/<год-месяц>.md` — **только если** владелец поправил,
   возразил, сказал «опять», показал дефект, либо ошибку поймала машина/самопроверка.
   Поле «поймал» заполняется честно.
2. Обновить `activeContext.md` (≤60 строк) и свой `context/<слот>.md` (≤120 строк).
3. `git add <файлы поимённо>` — **не `git add -A`**: затянешь правки соседнего слота.
4. Commit и **push**. Без push соседняя машина работает по вчерашней памяти.

## Правила, которые здесь действуют

**Не принимай вывод без артефакта — ни от себя, ни от кого-либо.**
Артефакт — это путь и номер строки, вывод команды, код ответа, идентификатор коммита.
«Я посмотрел, там всё в порядке» результатом не считается.

**Конфигурация ≠ состояние.** Спрашивай систему, что она РЕАЛЬНО применит, а не читай
файл. В этом проекте `grep` по файлу соврал бы минимум трижды: 68 схем компонентов,
которые Strapi не грузит; путь к БД, ведущий не туда; тип `api::icon.icon`, живущий
только в БД. Разбор — `memory-bank/patterns/catalog.md`, К-06.

**Отрицательный результат по одному пути ≠ отсутствие явления.** Прежде чем сказать
«такого нет», перечисли все механизмы, которые могли бы это обеспечивать, и покажи
проверку по каждому.

**Тест — часть работы, а не отдельная задача.** Изменение сделано, только если вместе
с ним создан тест на новое поведение, либо скорректирован существующий, либо назван
файл и кейс, который это покрывает. «Покрыто существующими тестами» без имени файла
не принимается. В этом проекте тестов **ноль** — значит первый же тест придётся написать.

🔒 **Замок готовности: мера не считается внедрённой, пока проверка не поймала
искусственный инцидент.** Поставил хук на секреты — подсади фальшивый ключ и убедись,
что коммит упал. Закрыл публичный роут — дёрни его `curl` и убедись, что 401.

⛔ **Секреты в репозиторий не пишем.** Только плейсхолдеры `${STRAPI_API_TOKEN}`.
Значения — в `memory-bank/secrets.local.md` (в `.gitignore`).
⚠️ В истории git этого репозитория уже лежат боевые ключи — см. B-01 в `backlog.md`.

## Ловушки именно этого проекта

- **Документы в `docs/` принадлежат трём поколениям архитектуры и не помечают друг
  друга отменёнными.** Прежде чем применить инструкцию — определи её поколение по
  `memory-bank/topics/architecture.md`. Документ января 2026 описывает дерево сайта,
  которого больше нет.
- **Даты в `docs/` не совпадают с git.** Репозиторий залит сквошем `349101c` (2026-03-04);
  хронология восстанавливается только по текстам документов.
- **`TODO`/`FIXME` искать бесполезно** — их в коде ноль. Незавершённость видна по
  мёртвым веткам, заглушкам `action="#"` и недостижимым `if`.
- **Прежде чем писать скрипт — `ls mgts-backend/scripts | grep <тема>`.** Там 329 файлов,
  и почти наверняка нужный уже есть в трёх версиях.
- **Правишь схему компонента — убедись, что правишь плоский файл**
  `src/components/<группа>/<имя>.json`, а не одноимённую папку со `schema.json`:
  вторых 68 штук и Strapi их не читает.

## Карта проекта в одну таблицу

| Каталог | Что |
|---|---|
| `mgts-frontend/` | Next.js 16 App Router — целевой фронт |
| `mgts-backend/` | Strapi 5.36 + 329 скриптов миграции + 2.4 ГБ медиа |
| `design/` | Живой легаси-слой: Stitch-блоки, шаблоны `tpl_*.html`, бандл Tailwind. **Читается рантаймом фронта** |
| `SiteMGTS/` | Замороженная копия старого сайта, 143 HTML. Источник контента, не поле для правок |
| `docs/` | Документация трёх поколений. Знания выжаты в `memory-bank/topics/` |
| `scripts/` | Оркестрация: `dev/`, `mapping/`, `stitch/`, `page_analysis/`, `qa/` |
| `memory-bank/` | Память между сессиями. Начинать отсюда |
| `_to_delete/` | Архив поколения A. Читать только как историю |

## Локальный запуск

```bash
./scripts/dev/start_all.sh        # статика :8002 + Strapi :1337
cd mgts-frontend && npm run dev   # Next :3000
```

Подробности, reset БД, флаги окружения — `memory-bank/topics/strapi-runbook.md`.
