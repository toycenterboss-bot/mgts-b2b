# Геометрия Москвы для карты

Дата: 19.08.2026 | Статус: в работе | Отменяет: —

`moscow.json` — 80 КБ. Координаты нормированы **по контуру города**: сам контур
строго в **[-1…1]**, а Зеленоград и анклавы лежат за МКАД и честно выходят
за единицу — районы до **−1.27**, острова до **−1.24**, узлы до **−1.21**.

⚠️ Первая редакция этого README утверждала «все координаты в [-1…1]». Неверно:
поймал тест `mgts-frontend/tests/geo-contract.test.ts` через десять минут после
того, как я это написал. Потребитель, который обрежет по единице, потеряет
Зеленоград.
Используется как подложка героя, блок внутри раздела и карта кейсов.

| Ключ | Что | Объём |
|---|---|---|
| `outline` | контур города | 670 точек, x −0.783…0.783, y −1.000…1.000 |
| `islands` | Зеленоград и 4 анклава | 5 |
| `districts` | полигоны районов | 129 |
| `moskva` | Москва-река | 8 сегментов |
| `yauza` | Яуза | 1 |
| `nodes` | узлы схемы связности `[x, y, вес]` | 129 |
| `edges` | рёбра, индексы узлов | 170 |

**Лицензия: OpenStreetMap, ODbL. Атрибуция обязательна** — строка
`© OpenStreetMap contributors, ODbL` есть в схеме `map.moscow-map` по умолчанию.

## 🔴 Границы честности — не размывать

**Схема связности условная.** 129 узлов — центроиды районов, 170 рёбер — ближайшие
соседи. Это **не трассировка ЛКС**. Написано в интерфейсе, а не только здесь:
иначе оператор примет картинку за карту ёмкости.

**Адресов площадок в файле нет и не будет.** Решение владельца: 40 площадок
показываем маркерно, `sitePrecision: district`. Публичная карта с точными
координатами критической инфраструктуры — подарок тому, кто планирует
физическое воздействие.

### 🔴 Два справочника районов НЕ соединяются по координатам

Замер 19.08:

```
названий в districts_named.json : 125
полигонов districts в moscow.json : 129
узлов схемы nodes                 : 129
центроидов, совпавших с узлами    : 0 из 125
расстояние до ближайшего узла: мин 0.0006 · медиана 0.0147 · макс 0.0624
```

Центроиды в справочнике имён посчитаны **другим способом**, чем узлы схемы связности:
совпадений нет ни одного, расхождение доходит до 6 % полуширины города
(район Метрогородок). Плюс имён на четыре меньше, чем полигонов.

**Что это значит для Ф5.** Точка кейса ставится по названию района — то есть
из `districts_named.json`, и она **не сядет** на узел схемы. Это нормально:
узлы — условная схема связности, а не карта районов. Но соединять эти два файла
по координатам нельзя, только по названию, а названий на 4 меньше.

**Чего не хватает:** какие именно 4 полигона остались без имени. Выяснится, когда
понадобится подписывать районы — сегодня подписи нигде не выводятся.
