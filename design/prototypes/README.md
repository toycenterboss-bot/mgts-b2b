## 🔴 Прототип — не требования

Класс **К-16**: однажды я уже выдал прототип за согласованный набор требований.
Прототип фиксирует **решения по ходу**, а не то, что обязано быть построено.

Что из прототипа уже переведено в требования и живёт в репозитории:

- параметры вида карты → компонент `design/strapi-new/components/map/moscow-map.json`;
- структура секций главной → `design/strapi-new/components/home/*`;
- карточка кейса и три носителя показа → `case/media-slot.json`.

Всё остальное в этих файлах — **иллюстрация**, а не спецификация.
