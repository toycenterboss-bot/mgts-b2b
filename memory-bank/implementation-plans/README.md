# Планы работ

Здесь лежат планы. Пока их нет — задачи живут в `../backlog.md`.

## Когда заводить план вместо строки в бэклоге

Когда работа не помещается в одну задачу с одним DoD: несколько фаз, зависимости
между ними, риск застрять посередине. На сегодня кандидаты — B-01 (отзыв секретов
+ чистка истории + хук) и B-03 (воспроизводимость с нуля).

## Скелет плана

```
## 0.0 ТАБЛО СОСТОЯНИЯ         ← где остановились (обязательно для планов >300 строк)
## 0. Факты (замер ДД.ММ)      ← заземление на реальность
## 1. Цель и критерий успеха
## 2. Метод (+ чем плохи альтернативы)
## 3. Фазы Ф1..Фn
## 4. Риски и уроки
## 5. Открытые вопросы Q1..Qn  ← решения владельца, не угадывать
## N. Артефакты и метрики по фазам
## DoD и Замок готовности
```

## Принципы, без которых план не работает

**Заземление на реальность.** Меряй текущее состояние ДО предложений: `grep` по коду,
запрос к базе, реальные числа. Раздел «Факты (замер с датой)» обязателен.
**Память врёт, факт — нет.**

**Каждой фазе — тройка: Артефакт · Метрика · DoD.**

**Метрика ловит тихую неправду, а не «стало лучше».**
Хорошо: «0 расхождений», «`grep`: второй реализации нет», «код ответа 401».
Плохо: «работает лучше», «быстрее», «точнее».

**Замок готовности** — один инвариант, охраняющий главный способ провала. Наш:
🔒 **мера не считается внедрённой, пока проверка не поймала искусственный инцидент.**

**Развилки — явными вопросами.** Что нельзя решить за владельца — оформляй как `Q1..Qn`
в отдельном разделе, а не рассыпай по тексту фразами «уточнить у заказчика».

## Табло состояния (§0.0)

Одно место, где видно «где остановились», без чтения плана целиком. Содержит:
счётчики по каждой оси (`✅ работает · 🟡 частично · ⬜ нет`); построчный список со
статусом и колонкой «чего не хватает»; 🔴 различие «мера есть» ≠ «проверка работает»
(нет проверки → статус 🟡, каким бы законченным ни выглядело дело); «что брать
следующим» — 2–3 пункта с обоснованием; дату последней сверки с реальностью.

**Обновляется тем же действием, что меняет состояние.** Отдельной задачи
«обновить табло» не существует — она не исполняется.

## Требование к шапке любого документа в этом проекте

Урок, выведенный из археологии `docs/` (см. `../patterns/catalog.md`, финальный раздел):

```
Дата: ДД.ММ.ГГГГ | Статус: черновик|в работе|закрыт | Отменяет: <файл или «—»>
```

Без этой строки документы «COMPLETE», «FINAL» и «SUMMARY» размножаются поверх друг друга,
не указывая, кто кого перекрыл. В `docs/` так накопилось 12+ взаимно противоречащих
«финальных статусов».
