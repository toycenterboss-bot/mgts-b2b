## Когда заводить план

Когда работа не помещается в одну задачу с одним DoD: несколько фаз, зависимости
между ними, риск застрять посередине. Мелкий локальный фикс плана не требует.

Кандидаты, до которых пока не дошли: **B-01** (отзыв секретов + чистка истории + хук)
и **B-03** (воспроизводимость с нуля).

## Что проверяет машина

`check-memory.sh` §9 обходит все планы в этой папке и краснеет, если:

- нет раздела `## 0.0` — табло состояния (принцип 13);
- у фазы нет строки `**Откат.**` — фаза без отката считается необратимой (принцип 11);
- у закрытой фазы нет поля «Что НЕ доказано» (принцип 12).
