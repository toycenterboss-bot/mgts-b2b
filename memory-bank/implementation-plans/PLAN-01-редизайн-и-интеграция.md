### Четыре блокера

**Б-1 · У трёх шагов нет входа.** `find` по репозиторию: `moscow.json`,
`districts_named.json`, `geocode-sites.py`, схемы 11 компонентов, `api::geo`, `api::case`,
прототипы — **ноль совпадений**. Всё живёт файлами у владельца. B-24 не входит
в порядок работ, хотя блокирует 3 шага из 11.

**Б-2 · Пишущие эндпоинты открыты анонимно.** `src/api/page/routes/custom-page.ts`:
`DELETE /pages/delete-all`, `POST /pages/update-parent-relations` и **пять**
`POST /pages/seed-*` — у всех `auth: false`. Шаг 8 — это день ручной работы владельцев
направлений в админке, который стирается одним анонимным запросом. Закрывать **до** шага 8.

**Б-3 · DoD темы измеряется инструментом с перевёрнутым знаком.**
`mgts-frontend/scripts/visual-compare.js` сравнивает React со **старой статикой**.
Базовая линия (118 страниц): медиана **7.03 %**, p75 14.48 %, p90 17.75 %,
макс 34.65 % (`/search`), мин 1.55 %. Но редизайн по замыслу уводит от старой статики —
после смены темы расхождение **вырастет, и это будет успехом**. Порог «медиана ниже X»
на этом эталоне назначить нельзя.
Чинится сменой эталона: снимать React **до** и React **после**, требовать, чтобы диф
объяснялся только цветом и типографикой, без сдвигов раскладки.

**Б-4 · Тесты писать нечем.** В `mgts-frontend/package.json` нет ни `vitest`, ни `jest`,
ни скрипта `test`. `playwright` и `pixelmatch` стоят, но только под `visual-compare`.
DoD требует тест «DZ = свитч» и e2e формы — пока раннера нет, оба замка это обещания.

## 6. DoD и Замок готовности

🔒 **Мера не считается внедрённой, пока проверка не поймала искусственный инцидент.**

- Тема: снимок React **до** и **после**; расхождение объясняется только цветом
  и типографикой, сдвигов раскладки нет (порог по геометрии блоков — 0).
  ⚠️ Старый эталон (React против легаси-статики, медиана 7,03 %) для этого не годится —
  редизайн уводит от статики намеренно. Подробно — §0.1, Б-3.
- Компоненты: тест «DZ = свитч» красный при подсаженном фиктивном компоненте.
- Кэш: правка в админке видна сразу; при отключённом webhook — не видна.
- Формы: e2e отправляет форму, бэкенд получил все поля.
- Карта: на странице без карты запроса за геометрией нет.
