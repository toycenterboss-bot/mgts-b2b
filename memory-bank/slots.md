# Слоты

Слот = поток работ + своя ветка + свой файл `context/<слот>.md`.

🔴 **Главное правило: сверять ветку ПЕРЕД КАЖДЫМ коммитом** (`git branch --show-current`).
Если слоты делят одну рабочую копию, сосед может переключить ветку под тобой.

⚠️ **Пиши только в свой `context/`.** Надо передать факт соседу — пиши в `topics/`
(это общее знание). Чужие оперативные файлы не редактируются.

## Когда заводить второй слот
Когда появится второй параллельный поток работ. Тогда же:
`git worktree add ../runs-<слот> <ветка>` — это правильный способ, дисциплина сверки хуже.
