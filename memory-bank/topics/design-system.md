в репозитории пока не лежат (см. «Что не сделано» внизу).

## Направление: «инженерная точность»

Выбрано владельцем из трёх вариантов. Тёмная база, но вместо стоковых картинок —
собственная графика: реальная карта Москвы, живые метрики, инструментальная эстетика.
Радиусы 2–3 px, волосяные линии, сетка из зазоров в 1 пиксель, никакого свечения.

**Претензия, из которой всё выросло** (коммерческий директор, отвечает за PropTech,
InfraTech и спецпользователей): *сайт не выглядит инновационно и дорого*.

Что реально двигает эти два критерия — проверено на итерациях:

| Рычаг | Вклад |
|---|---|
| **Типографика** | самый сильный. Системный шрифт = «дёшево» независимо от остального |
| Ритм чёрное ↔ кость | секции чередуются, а не сплошной тёмный SaaS-дефолт |
| Данные как типографика | цифры в 100 px — самостоятельные объекты, а не подписи под иконками |
| Зерно поверх | убирает пластиковость плоских заливок |
| Собственная графика | карта Москвы вместо стока |
| Отказ от скруглений и теней | инструментальность вместо «карточек» |

## Токены

```
--ink       #05070B   глубокий чёрный, «инженерные» секции
--ink-2     #0B1017   --ink-3 #121A24
--bone      #F2F0EC   тёплая кость вместо белого — читается дороже
--bone-2    #E7E4DE   --bone-3 #D8D4CC
```

**Дивизионы — цвета из стратегии, стр. 9:**
`--proptech #1B3A8F` / светлый `#6E9BFF` · `--infratech #0091EA` / `#4FC3F7` ·
`--rnd #6C3FB4` / `#B48CFF` · `--brand #0A6FE0`

🔴 **Две роли одного синего — то, чего не хватало старой теме.**
`--brand #0A6FE0` только для **заливок** (белый на нём 4.81:1 → AA).
`--brand-text #6CB4FF` на тёмном / `#0057B8` на светлом — только для **текста и линий**.
Исходный `#0A84FF` не может обслужить обе роли: белым по нему 3.65:1 — провал.

**Текст, три уровня.** Тёмная: `#EAF0F8` 16.5:1 · `#A8B6C9` 9.2:1 · `#7C8CA3` 5.5:1.
Светлая: `#0B1220` 18.7:1 · `#44536A` 7.8:1 · `#5C6B82` 5.4:1.
Ниже третьего уровня не опускаться.

**Шрифты.** Прототип: Unbounded 700 (акциденция, цифры) + Manrope 400/500/700/800.
Оба с кириллицей, встроены base64 — работает офлайн. В продакшене — MTS Sans через `next/font`.

**Прочее.** Отступы 4·8·12·16·24·32·48·64·96. Сетка 12 колонок, макс. 1360.
Движение 150–200 мс, `cubic-bezier(.19,1,.22,1)`. Цифры — `tabular-nums` везде.

## Темы — это токены, а не перекрытия

Светлая и тёмная переключаются сменой `data-theme` на `<html>`.
**Ноль `!important`** против 181 в текущем `light-theme.css` (689 строк).
В прототипе есть переключатель — можно убедиться, что тема не разваливается.

## Доступность: замеры, не мнение

Контрасты считались по формуле WCAG из пикселей скриншота текущего сайта
(`docs/project/visual-compare/react/home.png`) и из токенов макета.

| Что | Было | Стало |
|---|---|---|
| подпись «24/7 · Мониторинг» | **1.67:1** ❌ | 17.5:1 |
| подпись «100 Гбит/с» | **2.08:1** ❌ | 5.5:1 |
| ссылка «АУДИТ» в карточке | **2.28:1** ❌ | 8.7:1 |
| body карточки сервиса | **3.16:1** ❌ | 9.2:1 |
| метка «FOR DEVELOPERS» | **3.06:1** ❌ | 5.5:1 |
| заголовки колонок подвала | **3.45:1** ❌ | 16.5:1 |
| белый на кнопке-заливке | 3.65:1 ❌ | 4.81:1 |

**Причина системная:** фирменный синий использовался как цвет мелкого текста на тёмном,
где он физически не может дать 4.5:1.

Плюс: `:focus-visible` 2 px с отступом на каждом интерактивном элементе;
развилка проходится с клавиатуры и подсвечивает карту по `focus`, не только по `hover`;
анимация выключается по `prefers-reduced-motion`.

## Структура главной

Герой = **развилка**, а не картинка. Шесть входов над сгибом: три крупные карты
(Девелоперам · Операторам связи · Личный кабинет) и четыре компактные
(Городу · BigTech и ЦОД · Промышленности · Спецпользователям). Плюс тихая строка
форварда на МТС Бизнес.

Дальше: клиентские факты → два дивизиона → лестница зрелости → R&D → Город →
карьера двумя треками → клиенты → новости → контакты с тремя контекстными CTA.

**Правило CTA:** одного главного нет. Кнопка «Обсудить проект» в шапке видна всегда,
у каждого раздела своё действие в конце. Решение владельца.

## Вертикальная адаптивность

Секции `clamp(52px, 8.4vh, 120px)`; заголовок `clamp(30px, min(4.4vw, 8.4vh), 62px)` —
реагирует и на ширину, и на высоту. Медиазапросы по высоте окна: до 820 px ужимается
шапка, до 730 px прячется блок «95 %» и второй ряд сегментов, до 620 px — описания.
Проверено на 1920×1080, 1440×900, 1366×768, 1280×720 — развилка помещается везде.

⚠️ Найденный при этом баг вёрстки: правило вида `padding: X 0 0` на элементе с классом
`.wrap` убивает горизонтальные поля контейнера. На 1440 маскируется авто-полями,
на 1366 текст прилипает к краю экрана. Использовать `padding-top`.

## Честность цифр зашита в схему

У каждого числового поля новых компонентов есть `verified: boolean` и `source: string`.
`verified: false` → в проде не публикуется. У отзывов `quoteApproved`, у логотипов
`clientLogoApproved`, у карты `sitePrecision: district|exact`.

В прототипе это видно кнопкой **«Показать заглушки»** — неподтверждённые цифры
подсвечиваются оранжевым. Список того, что подтверждено, а что нет, — доставлен
отдельным документом «ЦИФРЫ на согласование».
