## Главный вывод, который стоил исследования

Визуальные расхождения — **не «недоделанная вёрстка»**. Корневая причина:
`design/tailwind/tailwind.config.cjs:3` сканирует `../html_blocks/**/*.html` и
не включает `mgts-frontend/src/**/*.tsx`, а `tailwindcss@4` во фронте не подключён
директивами и утилит не генерирует вовсе. Часть классов, написанных в React, просто
не имеет CSS. Это B-04 и, вероятно, самая дешёвая по трудозатратам крупная победа.

## Что НЕ сделано и почему

- **Секреты не отозваны** — это действие вне репозитория, требует доступа владельца
  к консолям Perplexity, Strapi admin и Penpot. B-01.
- **История git не чищена** — требует `git filter-repo` + force-push, то есть
  согласования (у репозитория могут быть другие клоны). B-01.
- **Хук `pre-commit` с gitleaks не установлен** — установка без прогона мутации была бы
  К-05; отдельный шаг в B-01.
- **Graphifyy не использовался** — MCP-инструмента в этой сессии нет; решение владельца —
  обойтись без него.
- **Q1–Q5 не отвечены** — это решения владельца, угадывать нельзя (см. `backlog.md`).
