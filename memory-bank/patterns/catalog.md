# Каталог классов ошибок — MGTS B2B

🔴 **Этот файл не читают подряд.** Его открывают в двух моментах:
1. **перед правкой** — пробежать по колонке «Триггер», найти свой случай;
2. **перед тем как назвать задачу сделанной** — предъявить «Артефакт».

Классы извлечены из практики **этого** проекта (археология `docs/` + аудит кода
2026-08-14), а не взяты из чужого списка. «Следы» — конкретные случаи с путями.
Новые следы добавляются при разборе `inbox/`.

## Правило, которого не хватало этому проекту

Причина §«Противоречия» целиком — отсутствие одного требования к документам:

> **Каждый документ обязан иметь в шапке `Дата | Статус | Отменяет: <файл>`.**

Без него «COMPLETE», «FINAL_REPORT» и «SUMMARY» размножаются поверх друг друга,
не указывая, кто кого перекрыл. Итог — 12+ взаимно противоречащих «финальных статусов»
и три разных числа общего прогресса (40 % / 50 % / 70 %) под одной датой.
